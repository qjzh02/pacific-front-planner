# 人工采集样本

这些文件只包含解析器需要的标题、条件、敌军战力和弱点节点，由测试代码人工构造。它们不包含原始游戏页面、账号信息、脚本、资源链接或玩家实际阵容，不代表真实战局。

`关键区域5.txt` 人工加入敌军减益标记，用于验证拒绝重复扣减；其中数值不是战斗前原战力。

0.2.0新增7份人工样本，覆盖区域禁用舰种、飞机联合禁用、禁用变项、忽略全域，以及带入8%取整还原。舰种图标只有人工命名的相对路径，不包含游戏图片文件或远程资源。原战力还原案例使用已核对的数值作为回归参考，不包含账号、阵容、库存或其他玩家状态。

文件名只为对应回归用例，实际条件始终按正文栏目解析；`关键区域-全域禁用变项.txt` 的正文特意构造成“区域”禁用变项，不能按文件名判断条件范围。
